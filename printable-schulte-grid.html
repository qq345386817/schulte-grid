Printable Schulte grid practice

Generate free 3x3, 4x4, 5x5, or 6x6 Schulte tables online. Each worksheet has a different number arrangement on white A4 paper, ready for screen-free practice at home or in a classroom.

When printed grids help

Use printed sheets when you want the same visual search exercise without notifications, app switching, or screen fatigue. They also work well when several people need practice sheets at the same time.

How to practice

  1. Open the online worksheet generator, choose a grid size, and select 1 to 20 sheets.
  2. Choose Print / PDF. In the browser dialog, select A4 paper and print, or use Save as PDF for a downloadable file. Turn off browser headers and footers for a cleaner sheet.
  3. Start with the smallest number and find each next number in order.
  4. Use a timer if you want to compare rounds.
  5. Repeat with a fresh sheet or a larger grid size when ready.

Print in your browser or in the app

The online generator is free and needs no account. Dark themes never change the white paper background. Each generated page contains one grid, with space for a name and time. The iPhone, iPad, and Mac app also generates printable practice pages for a native daily routine.
